# 浏览器会话归档（2 分钟）

## 已装过？只需更新（不用重装）

1. `edge://extensions`
2. 在「**GPT Audio Dictation**」卡片上点「**重新加载**」
3. 回到 ChatGPT 页面**刷新一次**

> 更新后重新加载扩展，然后刷新 ChatGPT。归档会读取会话侧栏和会话首条命名消息来推断日期；日期未知的记录不会自动猜测。

## 安装

从 Release 解压 `gpt-audio-dictation-extension-1.4.0.zip`，或直接选择解压包里的扩展目录。注意：浏览器必须选择**直接包含 `manifest.json` 的那一层**，不要选择 zip 或它的父目录。

1. 打开 `edge://extensions`。
2. 打开“开发人员模式”。
3. 点“加载解压缩的扩展”。
4. 选择直接包含 `manifest.json` 的扩展目录。
5. 刷新 ChatGPT 页面。

## 怎么确认装上了

- `edge://extensions` 列表里出现“GPT Audio Dictation”，版本 `1.4.0`。
- 工具栏出现扩展图标。
- 装完**刷新一次 ChatGPT 页面**（`https://chatgpt.com`），否则面板不会出现。

## 打开面板

点工具栏的扩展图标 → 右下角出现悬浮条 → 点标题栏展开。

## 归档 5 步

1. 展开面板，找到「**归档**」区。
2. 选「从」「到」两个日期（含两端）。
3. 点「**检索会话**」——会逐个打开候选会话读取**第一条消息**来定日期（标题可能是通用的，不可靠）。
4. 勾选要保存的会话（可点「全选」）。
5. 点「**保存到文件夹**」。

## 文件位置

`<浏览器下载目录>\课程归档\<开始日期>_到_<结束日期>\<文件名>.md`

通常位于 `C:\Users\<用户名>\Downloads\课程归档\...`，可在 Edge「设置 → 下载」查看或修改。

> 安装时**不会弹任何权限框**，不用点「允许」。
> 第一次保存也**不弹窗**，文件直接进下载目录。
> 只有提示「ZIP 兜底」时才可能出现「允许下载多个文件」，点允许即可。

归档会尝试读取登录态中的 ChatGPT 会话内容；如果接口不可用，只能对当前打开的会话使用页面可见内容兜底。无法确认完整性时会默认拒绝保存，除非你明确勾选“允许保存不完整内容”。
